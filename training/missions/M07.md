# M07: Multi-agent orchestration

APT Enterprise AI Lab · 4 hours · progressive mission

## Business ticket
Map actors, handoffs and state. Introduce a failed handoff, cap loops and record recovery.

## Starting point
[Inspect upstream reference: advance_ai_agents/content_team_agent](https://github.com/Arindam200/awesome-ai-apps/tree/main/advance_ai_agents/content_team_agent). A reference example, not a completed submission.

## Knowledge base
Trace each user input through configuration, model API or tool, data boundaries and response. Distinguish application code, external dependencies, secrets, tests and observable behavior. Identify the relevant quality property: correctness, grounding, latency, cost, access control or resilience.

## Assignment
1. **Inherit:** run the example, capture setup, versions and baseline.
2. **Investigate:** map entrypoint, flow, interfaces and dependencies in `architecture.md`.
3. **Modify:** implement the ticket and record changed files and rationale.
4. **Break:** reproduce one controlled failure, without exposing credentials or production data.
5. **Fix:** add success, invalid-input and regression tests; compare before/after evidence.
6. **Defend:** submit `investigation.md`, `decision-record.md`, logs and a short technical defense.

## Acceptance
Reproducible setup; documented failure; independent verification; no committed secrets; reasoned security, latency and cost tradeoffs. Instructor should provide hints progressively rather than naming the source file.
