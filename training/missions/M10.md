# M10 — Enterprise incident capstone

**APT Enterprise AI Lab** · 4 hours · mission 10/10

## Business incident
Diagnose stale answers plus elevated latency with unknown root cause; prove the fix using tests, logs and postmortem.

## Reference code
[rag_apps/agentic_rag](https://github.com/Arindam200/awesome-ai-apps/tree/main/rag_apps/agentic_rag). This is an example to study and adapt, not a claim that the task is implemented.

## Concepts and knowledge base
Map the request lifecycle, trust and network boundaries, configuration, model/tool calls, dependencies, logs and user-visible response. Explain the relevant reliability, security, test and operating principles. Identify assumptions that require verification. For every observed defect, record the reproduction steps, expected behavior, actual behavior and causal evidence.

## Progressive assignments
- **Inherit:** reproduce a working baseline; document setup, environment variables and dependencies (never commit secrets).
- **Investigate:** write `architecture.md` and draw the request and data-flow diagram; locate ownership boundaries.
- **Modify:** implement the business ticket with a focused change and explain tradeoffs.
- **Break:** inject a safe, isolated failure; record symptoms and hypotheses.
- **Fix:** restore behavior using evidence and tests; compare pre/post results.
- **Defend:** present `investigation.md`, `decision-record.md`, test evidence and a concise incident debrief.

## Acceptance criteria
- Independent reviewer can reproduce a baseline and a failure test.
- Success, malformed input and failure paths are covered.
- No unapproved external actions or exposed credentials.
- Root cause follows from observable evidence.
- Reliability, security, cost and latency tradeoffs are explicitly discussed.

## Instructor notes
Offer incident symptoms before hints. Do not identify target files for learners unless an accessibility accommodation requires it. Deduct points for unsupported explanations. Use rubric: investigation 25, implementation 25, tests 20, operations and security 15, defense 15.
